# Raspberry Pi 5 setup

This project starts with a basic Raspberry Pi 5 bring-up.

Use Raspberry Pi Imager to install Raspberry Pi OS Lite (64-bit), apply a custom system configuration, enable SSH, and verify that the board is reachable after the first boot.

References:
- https://www.raspberrypi.com/software/
- https://www.raspberrypi.com/documentation/computers/getting-started.html
- https://www.raspberrypi.com/documentation/remote-access/ssh/
